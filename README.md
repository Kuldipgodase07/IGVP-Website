# IGVP — Indigenous Global Venture Partners

Modern, high-performance web platform for **Indigenous Global Venture Partners Inc. (IGVP)**. Building intelligent platforms for a digital world across AI, Data Engineering, Edge PKI, Healthcare, and Enterprise Transformation.

---

## 🚀 Overview & Key Features

1. **Brand Identity & Theme**:
   - Signature IGVP Blue theme (Neon Cyan `#16D9F2` & Electric Royal Blue `#1769FF`).
   - Deep dark aesthetic, glassmorphism navigation, and responsive typography.

2. **Core Pages**:
   - **Home (`index.html`)**: Hero presentation, core AI platforms (IGVP AI, Multi-Agent Orchestrator, BharatShield AI), industry solutions, and case studies.
   - **About (`about.html`)**: Who We Are, Leadership Team, values, technology ecosystem, and interactive leadership bio modals.
   - **Insights (`insights.html`)**: Enterprise thought leadership articles, dynamic category filtering, and rich modal reader.
   - **Careers (`careers.html`)**: Life at IGVP, core cultural pillars, open positions, and job application submission flow.

3. **Unified Footer**:
   - 4-column navigation grid (Quick Links, Services, PhAI, About Us).
   - Global presence: **US Office** and **India Office** with official flags.
   - For Business contact block (`info@igvp.ai`, `+1 (604) 601-2000`).
   - Slogan: *"Data to Decisions — Delivered"*.
   - Designer Attribution: *"Designed by: Kuldip Mahesh Godase"*.

## 🛠️ Technology Stack

- **HTML5 & Vanilla CSS**: Custom responsive design system with CSS custom properties and fluid layouts.
- **Vanilla JavaScript**: Lightweight, accessible DOM controllers with zero bloated runtime dependencies.
- **Vite**: Rapid local development and optimized static bundling.
- **Vercel Ready**: Preconfigured with `vercel.json` for clean URLs, routing, and CDN caching.

---

## 💻 Local Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Dev Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the site.

3. **Build for Production**:
   ```bash
   npm run build
   ```
   Generates optimized static assets in the `dist/` directory.

---

## 🌐 Deployment to Vercel

This repository is pre-configured for one-click deployment on [Vercel](https://vercel.com):

- **Build Command**: `npm run build`
